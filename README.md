## Requirements

- Bash
- R
- tidy verse
- dada2
- DECIPHER
- phangorn
- ape
- Biostrings

## Problem 1
Generate dummy FASTQ files and organize
them by condition and read direction.

## Problem 2
Organize the same FASTQ files using R
and compare the results with Bash.

## Problem 3
Calculate microbial sequencing yield
under a fixed budget.

## Problem 4
Process paired-end reads with DADA2
and construct a neighbor-joining tree.

## Problem 5
Calculate microbial and useful reads
after host DNA depletion.

## Problem 6
Calculate odds ratios, confidence
intervals, and predicted probability.

## How to run

Run the scripts from the project directory.
